# Credits

## The original project

**tv-ambient-home is built on [CleanYourTV](https://github.com/Gathin23/cleanyourtv)**, created by
**Gathin** ([@Gathin23](https://github.com/Gathin23)), and first published as *tv-vibehack*. Almost all of
the launcher, the debloat prompt, the ADB tools, the restore and drift-check scripts, the safety rules and
the troubleshooting knowledge come from that project and its community. If this repo is useful to you,
please star and support the original: <https://github.com/Gathin23/cleanyourtv> and <https://cleanyour.tv>.

This project started from the original's code as of commit
`2dcd4a81e240eefb57cf2c50263226651c665476` (via the mirror github.com/nguyenduchoai/tv-vibehack),
under the MIT licence. The original copyright notice is kept in [`LICENSE`](LICENSE).

## What this project adds

By Raghav Tripathi ([@raghavtripped](https://github.com/raghavtripped)), tested on a Xiaomi MiTV-MOOR2
(Google TV / Android 11):

- **Ambient light** add-on (`addons/ambilight`): a Bluetooth LEDDMX strip behind the TV that follows the
  picture through the TV's own colour taking, survives standby, reboots and updates.
- **Weather** and **Phone remote** add-ons (`addons/weather`, `addons/phoneremote`).
- Launcher changes: volume acceleration, a Bluetooth pill, the stock-home redirect for Google TV with voice
  search left working, and the fix that keeps that redirect from covering an app that is still starting.
- The debloat list for the MiTV-MOOR2 (`examples/xiaomi-mitv-moor2/debloat.txt`).
